📖 Panduan Troubleshooting

  1. Jika semua test gagal, pastikan folder api/ sudah di-upload ke public_html/bosp/api/
  2. Jika test-simple.php berhasil tapi sync.php error 500, cek error log di sync_error.log
  3. Jika error 404, pastikan file .htaccess ada di folder api/
  4. Jika error CORS, pastikan header CORS sudah di-set di config.php
  5. Cek console browser (F12) untuk detail error
