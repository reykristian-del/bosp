📖 Troubleshooting

  1. Jika health.php berhasil tapi health (router) gagal → masalah di .htaccess routing
  2. Jika semua gagal → file belum ter-upload atau URL salah
  3. Jika error 500 → cek error log di sync_error.log
  4. Jika response bukan JSON → ada error PHP yang tidak ter-handle
  5. Buka Console browser (F12) untuk detail error
